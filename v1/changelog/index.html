    更新日志

    1 版本说明¶

    版本号说明： 像其它优秀开源项目一样，SQLBot 将保持每月发布一个新的功能版本，功能版本中如遇较为紧急或严重的 Bug，将及时推出 Bug 修复的小版本。
    SQLBot 版本号命名规则为： v 大版本.功能版本. Bug 修复版本，示例如下：

    • v1.0.1 是 v1.0.0 之后的 Bug 修复版本
    • v1.1.0 是 v1.0.0 之后的功能版本

    v1.2.1¶

    新增功能

    • 智能问数：优化错误信息查看体验，添加滚动条，自适应宽度和高度。
    • 登录：提高登录页面背景图片的清晰度。
    • 数据源：修复'Session'对象缺少'exec'属性的问题。

    • 数据源：修复 Elasticsearch SSL 连接相关问题

    • 数据源：修复获取数据源表或模式时的线程阻塞的问题
    • 数据源：优化线程中的 SQLAlchemy Session，改进多线程环境下的数据库会话管理。
    • 小助手：修复助手用户标识的错误。
    • 系统操作：修复删除工作区后无法切换到其他工作区的问题。
