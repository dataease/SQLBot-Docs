## 1 版本说明

!!! Abstract ""
    **版本号说明：** 像其它优秀开源项目一样，SQLBot 将保持每月发布一个新的功能版本，功能版本中如遇较为紧急或严重的 Bug，将及时推出 Bug 修复的小版本。           
    **SQLBot 版本号命名规则为：** v 大版本.功能版本. Bug 修复版本，示例如下：

    - v1.0.1 是 v1.0.0 之后的 Bug 修复版本
    - v1.1.0 是 v1.0.0 之后的功能版本


## 2 更新内容

### v1.1.0

2025 年 9 月 4 日


!!! Tip  "新增功能 :star2:"

    - 数据源：支持 AWS Redshift、Apache Doris、ClickHouse 等新数据源。
    - 智能问数：图表支持直接添加到仪表板。
    - 智能问数：优化饼图中的标签和工具提示显示。
    - 智能问数：支持为智能问答助手新增助手调试页面及外观配置。
    - 智能问数：支持在聊天时使用术语。
    - 系统设置：增加外观菜单和系统外观设置。
    - 系统设置：增加对 Azure OpenAI 和 Universal OpenAI 支持。
    - 嵌入式管理：嵌入式功能支持页面嵌入和重置应用密码、内嵌页面路由和显示设置。


!!! Tip  "功能优化 :sunflower:"

    - 数据源：数据源接口支持 AES 加密。
    - 数据源：优化动态数据源获取版本。
    - 嵌入式：优化助手基础应用记录存储、CORS 配置、全屏嵌入代码。 
    - 嵌入式管理：优化页面嵌入逻辑和样式布局。
    - 系统设置：优化模型配置和验证。


!!! Tip  "问题修复 :palm_tree:"

    - 嵌入式管理：修复页面嵌入编辑功能和界面 URL 格式不正确的问题。
    - 智能问答：修复智能问答过程中的一些问题。
