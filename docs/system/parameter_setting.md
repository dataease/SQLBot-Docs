# 参数设置

!!! Abstract ""
    在系统设置中，参数设置用于统一管理与 SQLBot 运行相关的全局参数，
    以 `admin` 管理员账号登录平台后，依次点击【设置】 → 【系统管理】 → 【系统设置】 → 【参数设置】进入功能页面。


![参数设置入口](../img/user_manual/system/参数设置界面.png)

### 1 问数设置

!!! Abstract ""
    问答设置用于控制 SQLBot 在对话问答时的行为，包括是否展示思考过程、上下文记忆条数以及单次返回的数据量限制。

    - 在问数窗口中，控制模型思考过程默认展开或者关闭；

    - 支持关闭1000行的数据限制；

    - 更改上下文记录数,控制用户上下文记录轮数；

![问数设置](../img/user_manual/system/模型思考过程.png)

![问数设置](../img/user_manual/system/限制1000行数据.png)

![问数设置](../img/user_manual/system/上下文记录数.png)

### 2 第三方平台设置

!!! Abstract ""
    第三方平台设置用于控制当外部系统（如平台对接、单点登录等）接入 SQLBot 时，如何创建和归属用户账号。

    - 第三方自动创建用户；

    - 指定自动创建的第三方用户默认归属到哪个工作空间；

    - 决定自动创建用户在目标工作空间中的角色类型；

    **注意**：第三方平台设置为 X-Pack 功能。
